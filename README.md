# Library of Experiences

Development of an AI-Powered Web Platform for Exploring and Visualizing Lived Experiences of Mental Health Conditions

### 1. Project Description

This project aims to develop an AI-powered web platform that helps users explore mental health conditions through educational information, interactive visualizations, and lived-experience materials.

### 2. Problem Statement

Mental health conditions are often misunderstood, and stigma can negatively affect people experiencing them. Existing resources are fragmented: information websites explain what a condition is but not how it feels, interactive projects usually cover only one condition, and AI chatbots are not connected to verified content. The platform aims to improve users' understanding of these conditions and the experiences of people living with them by combining these approaches in one place.

#### Target users:

- People interested in learning about mental health.
- Relatives and friends of people with a mental health condition who want to understand and support them.
- People seeking to better understand their own experience and where to get help (the platform does not diagnose).
- Students and other users interested in mental health education.

#### Expected outcomes:

- An interactive web platform with a catalog of 5-10 mental health conditions based on the ICD-11 classification.
- Condition pages with educational information, interactive visualizations, personal stories, advice on how to help, and sources.
- An AI-powered assistant that answers questions based on the platform's content and refers crisis or diagnosis requests to specialists.
- A calm and user-friendly interface that supports mental health awareness.

## 4. Project Scope and Status

Scope: The project includes research of existing solutions, requirements analysis, interface design, web application development, integration of an AI component, and software testing.

In scope: catalog with search, condition pages, at least 3 types of interactive visualizations, personal stories with sources, AI assistant, help and support contacts.

Out of scope: diagnosis or therapy, crisis intervention, user accounts, mobile apps.

Current status: Analysis and design stage (pre-defense 1). The project proposal, literature review, existing system and technology comparisons, requirements, architecture diagrams, UX concept, and evaluation plan are completed. Development of the application has not started yet.

## 5. Selected Technologies

Frontend: React, JavaScript, HTML, CSS

Backend: Node.js, Express (REST API)

Database: PostgreSQL

AI integration: external AI model API (OpenAI or Gemini). The backend finds relevant content on the platform and sends it to the model together with the user's question, so answers are based on verified content.

Tools: Figma (prototype), Mermaid (diagrams), GitHub and YouTrack (project management), Jest (testing).
